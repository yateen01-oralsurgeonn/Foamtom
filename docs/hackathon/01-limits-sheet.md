# Kiroween 2026 — limits sheet

Read from kiroween.devpost.com/rules on 2026-11-07.

## Hard rules (break one = out)
- **Deadline:** 4 Dec 2026, 2:00 pm Pacific = **3:30 am IST on 5 Dec**. Submit on the evening of 4 Dec IST. No extensions.
- **Eligibility:** India is not excluded. Solo is fine (teams up to 3).
- **Built with Kiro** (IDE, CLI, Web or Crew). "Insufficient use of Kiro" = disqualified.
- **`/.kiro` folder at the repo root**, with specs, hooks and steering. Never in .gitignore.
- **New project only**, started after 30 Oct 2026. Disclose any pre-existing code or work (e.g. Toothy art).
- **Public GitHub repo** (not GitLab) with an open-source licence shown in the About box.
- **Working URL** judges can open, free, no restrictions until 29 Jan 2027.
- **Demo video under 3 min**, public on YouTube, English, no copyrighted music or third-party trademarks.
- **Write-up on how Kiro was used:** specs, hooks, steering, MCP, custom agents, property-based tests, powers.
- One category: Resurrection / Frankenstein / Skeleton Crew / **Costume Contest** (haunting UI that helps the app work).

## How it is scored (after a pass/fail check on theme + Kiro use)
Five criteria, 20% each:
1. Potential impact: real problem, real audience, would someone use it
2. Technological implementation: **how deeply Kiro was used**
3. Design: complete, polished product, not a proof of concept
4. Innovation / idea
5. Presentation: the video

## Prizes
- Overall: $30k / $20k / $10k. Category: $5k each. One overall OR one category prize, plus any bonuses.
- Bonuses that fit: Best Startup $10k (founder + LinkedIn + startup website), Best Demo $1k,
  Blog post (2,000 Kiro credits), Social Blitz (post starting with #KiroweenHackathon26, his own words).
- Not eligible: Student, Ghost of Kiroween Past (no 2025 entry).

## Admin
- Free 4,000 Kiro credits: request form needs a Kiro user ID; **deadline 1 Dec 12 pm PT**, allow 48 business hours. Request early.
- Kiro model availability varies by region: check India on kiro.dev.

## What this means for us
- The code is written **in Kiro**, not Claude Code. Claude helps with the idea, storyboard, steering-doc drafts, the
  video, the write-up and review.
- A web game hosted free (e.g. GitHub Pages) meets "working URL" most easily.
- Kids' app: no accounts, no data collected; if a camera or mic is used, process it in the browser only.
- No clinic contact or case claims in the app or video (DCI rules).
